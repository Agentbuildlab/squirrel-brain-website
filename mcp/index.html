Overview

What is the MCP server?

MCP (Model Context Protocol) is a standard that lets AI agents call tools on external services. Squirrel Brain exposes an MCP-compatible endpoint so that Claude (or any agent using the protocol) can interact with your personal brain directly.

This means an AI agent can:

Read your tasks Create items & notes Set alarms on your phone Send push notifications Send voice messages via Pip Fetch your daily brief

All actions are tied to your account via your API key. Only you can access your brain.

Who is this for? Developers, technical founders, and power users who want to wire Claude or a custom agent into their Squirrel Brain account. If you just want to use the app, no setup needed.
Authentication

Your API key

Every request to the MCP server must include your Squirrel Brain API key in the X-API-Key header. Your key is personal and ties all actions to your account.

How to get your key: API keys are tied to your Squirrel Brain account. During early access, email hello@squirrelbrainapp.com to request yours — we'll generate it and send it within 24 hours. In-app key generation is coming soon.
Endpoint
POST https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server
Required headers
Content-Type: application/json X-API-Key: sb_your_api_key_here
Request body shape (MCP standard)
{ "method": "tools/call", "params": { "name": "<tool_name>", "arguments": { /* tool-specific args */ } } }
Security note: Never expose your API key in client-side code or public repos. Use it only in server-side code or agent configurations that you control.
Tools Reference

Available tools

These are the tools your agent can call. All tools use the tools/call method.

Tool name Description Key parameters
create_item
 Create a task, note, or reminder in your Squirrel Brain. Appears in Memory Stash and your daily brief. title body due_date tags
create_alarm
 Set a loud alarm that fires on the user's phone at the specified time. Repeats until dismissed — not a silent push. title scheduled_for body
list_items
 Read the user's current tasks and notes. Supports filtering by type, date range, or completion status. type completed limit
get_daily_brief
 Fetch today's agenda: focus items, overdue tasks, completed wins, and pending items — the same content as the 5 AM email. no required params
notify_human
 Send a push notification to the user's phone immediately. Use this when the agent needs to surface something important in real time. title body
pip_call
 Send a voice message to the user via Pip (text-to-speech). Pip speaks the message aloud on the user's phone using the nova voice. message priority
Parameter types: scheduled_for accepts ISO 8601 strings (e.g. "2026-06-01T14:30:00Z"). type on list_items accepts "task", "note", or "alarm". limit defaults to 20, max 100.
Example Usage

curl examples

Replace sb_your_api_key_here with your API key.

Create a task
curl -X POST \ https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server \ -H "Content-Type: application/json" \ -H "X-API-Key: sb_your_api_key_here" \ -d '{ "method": "tools/call", "params": { "name": "create_item", "arguments": { "title": "Follow up with Marcus at Meridian", "body": "Send revised pricing and Riverside case study", "due_date": "2026-06-05T17:00:00Z", "tags": ["sales", "follow-up"] } } }'
Set an alarm on the user's phone
curl -X POST \ https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server \ -H "Content-Type: application/json" \ -H "X-API-Key: sb_your_api_key_here" \ -d '{ "method": "tools/call", "params": { "name": "create_alarm", "arguments": { "title": "Call Marcus — pricing deadline", "body": "He needs the revised numbers today", "scheduled_for": "2026-06-05T14:00:00Z" } } }'
Read current tasks
curl -X POST \ https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server \ -H "Content-Type: application/json" \ -H "X-API-Key: sb_your_api_key_here" \ -d '{ "method": "tools/call", "params": { "name": "list_items", "arguments": { "type": "task", "completed": false, "limit": 10 } } }'
Send a voice message via Pip
curl -X POST \ https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server \ -H "Content-Type: application/json" \ -H "X-API-Key: sb_your_api_key_here" \ -d '{ "method": "tools/call", "params": { "name": "pip_call", "arguments": { "message": "Hey, just a heads up — your 2 PM call with Meridian starts in 15 minutes.", "priority": "high" } } }'
Fetch the daily brief
curl -X POST \ https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server \ -H "Content-Type: application/json" \ -H "X-API-Key: sb_your_api_key_here" \ -d '{ "method": "tools/call", "params": { "name": "get_daily_brief", "arguments": {} } }'
Using with Claude: Add the endpoint and your API key to Claude's MCP server configuration. Claude will automatically discover the available tools and call them when relevant to the conversation.
Getting Started

Setup checklist

Follow these steps to connect your first AI agent to Squirrel Brain.

  • 1
    Download Squirrel Brain and create your account. Available on the App Store.
  • 2
    Request your API key. Email hello@squirrelbrainapp.com — your key is tied to your Squirrel Brain account and starts with sb_. In-app key generation coming soon.
  • 3
    Store the key securely. Add it to your agent's environment variables or secrets manager. Never commit it to a public repo.
  • 4
    Configure your MCP client. Point it at the endpoint:
    https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server
    with the X-API-Key header set to your key.
  • 5
    Test with a curl command from the examples above. A successful create_item call will show the new task in your Squirrel Brain app immediately.
  • 6
    Wire it into your agent. Use get_daily_brief to give your agent context about your day, create_alarm to set phone alerts, and pip_call to send voice messages when something needs your immediate attention.
Questions? Email us at hello@squirrelbrainapp.com. Include your use case and we'll help you get set up.
Quick Setup

Copy-paste config for your agent

Replace sb_YOUR_KEY_HERE with your API key. Don't have one yet? Email hello@squirrelbrainapp.com to request early access.

Add to ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "squirrel-brain": {
      "url": "https://geczbtsjfbvfukdzdemr.supabase.co/functions/v1/mcp-server",
      "headers": {
        "X-API-Key": "sb_YOUR_KEY_HERE"
      }
    }
  }
}
